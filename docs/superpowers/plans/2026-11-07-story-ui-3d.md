# Story UI with 3D building — implementation plan

> Executed inline in the same session (hackathon time). Spec:
> `docs/superpowers/specs/2026-11-07-story-ui-3d-design.md`.

**Goal:** a light, 3-step story page with a Three.js building as the hero visual.
**Architecture:** static HTML + ES modules, no build step. `scene3d.js` owns all 3D; `story.js` owns
the steps and talks to the backend only through Sakshi's `window.LO` (`js/api.js`).
**Tech:** Three.js r160 (vendored), plain JS/CSS, FastAPI backend unchanged.

## Global constraints
- No backend changes. `js/api.js`, `js/twin.js`, `twin.html` unchanged.
- Works offline from the venue Wi-Fi: Three.js served from `frontend/vendor/three/`.
- Light page theme; 3D panel has a dusk sky.
- Works at 1920×1080 and 1440×900; stacks under 1000 px wide.

## Task 1 — Vendor Three.js, keep the old dashboard
- Create `frontend/vendor/three/three.module.js` and `frontend/vendor/three/addons/OrbitControls.js`
  (three@0.160.0 from jsDelivr).
- `git mv frontend/index.html frontend/classic.html` (content unchanged).
- Check: `curl localhost:8000/vendor/three/three.module.js` → 200; `/classic.html` → 200.

## Task 2 — `frontend/js/scene3d.js`
Produces (ES module export):
```
createScene(container) -> {
  setBuilding({floors, cols, windows}), setWindows(windows), setWindow(id, state),
  setRiskView(bool), dispose()
}  // throws if WebGL is unavailable
```
- Building body, window InstancedMesh (front + back mirror), side fins, ground, dusk sky.
- Per-window fade (0.4 s) toward target color; risk view tint; birds (~25) reacting to lit fraction.
- Auto-orbit, OrbitControls drag, resume after 4 s; pause when tab hidden.
- Check: page renders the Demo Hall; a `{id,state}` command visibly fades one window.

## Task 3 — `frontend/index.html` + `frontend/css/story.css`
- Top bar (brand, building picker, status dot, clock, ⋯ menu), step bar, 3D panel with legend +
  risk toggle, step card with three panes, before/after slider section, toast.
- Check: screenshots at 1920×1080 and 1440×900 look right in light theme.

## Task 4 — `frontend/js/story.js`
Consumes `window.LO` (`api()`, `connectSocket`, `speak`, `url`, `fake`) and `createScene`.
- Load building + conditions; WebSocket handlers; step navigation; scenario buttons; decide →
  apply response windows → step ③ (animated numbers, reason, source tag, voice); Start over → reset.
- Before/after slider with detected-windows toggle; hide when no photo.
- Fallbacks: WebGL/Three failure → flat `LightsTwin` grid; decide error → toast, stay on ②.
- Check (headless Chrome via playwright-core): full flow Foggy → Decide → step ③ shows
  risk drop and source; no console errors; fake mode flow works with the backend stopped.

## Task 5 — Verify and commit
- Run backend tests (unchanged backend) and the browser flow; commit frontend + plan.
